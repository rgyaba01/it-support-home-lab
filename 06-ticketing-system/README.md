# IT Ticketing System

This section contains simulated IT Service Desk incidents and demonstrates how support tickets can be investigated, prioritised, resolved and documented.

## Ticket Lifecycle

1. Ticket received
2. Issue categorised
3. Priority assigned
4. Initial investigation
5. Troubleshooting
6. Escalation if required
7. Resolution
8. User communication
9. Ticket closure

## Skills Demonstrated

- Incident management
- Ticket prioritisation
- Troubleshooting
- Escalation
- User communication
- Documentation
- Problem solving

## Ticket Scenarios

This section will contain simulated IT support tickets covering common Service Desk issues such as:

- Email access problems
- Password and account issues
- Network outages
- Printer problems
